# OpenDPI
Защитный шлюз (aka. Бутылочное горлышко) инфраструктуры от:
- DoS
- DDoS
- Slowloris
- Land Attack
- LFI / Path Traversal (Local File Inclusion)
- Web-Scanning

Шлюз устанавливает лимиты на количество пакетов в секунду по TCP, размеры пакетов, скорость отправки, WS-подключений, размер WS-сообщений, время на WS-подключение и так далее, а затем раздаёт баны нарушителям.

## Модули
- `net`: Модуль с низкоуровневой логикой работы с сетью.
- `proxy`: Модуль для работы с reverse-proxy (http, https, ws).
- `security`: Модуль содержащий алгоритмы анализа входящих пакетов.
- `conf`: Модуль для сбора конфигурации работы DPI.
- `core`: Ядро DPI, на основании конфигурации подбирает оптимальный toolchain.


## Что OpenDPI не делает
**OpenDPI** — это фильтр трафика, а не балансировщик и не CA. Он стоит перед reverse-proxy и решает «пускать или нет» на основе правил безопасности. Он не занимается маршрутизацией между бэкендами, не терминейтит TLS для бэкенда и не выдаёт сертификаты. Эти задачи решают другие инструменты (nginx, traefik, cert-manager, vault), и OpenDPI потребляет результаты их работы.
