# 1. Сетевые типы данных. /net/addrs[.cpp / .hpp]

## net::SocketAddr
Класс для работы с полными адресами (IP и порт).
- Умеет работать как с человеческим представлением адреса (IP:PORT) так и POSIX-совместимыми структурами (sockaddr_in, sockaddr, socklen_t).
- Умеет работать с DNS (Если передать localhost:80 или google.com:80 - ничего страшного не произойдёт, если интернет есть, гугл будет виден XD).
- Умеет сравнивать адреса (Для хранения адресов в std::map и std::set. Актуально больше для IpAddr).
- Легко собирается из строк из POSIX-структур.
- Может создаваться из `IpAddr + (int)port`;

## net::IpAddr
Класс для хранения IP адреса, без порта. По большей мере нужен лишь для хранения адреса.
- Компактно хранит адрес в 4 байта.
- Может создаваться из `SocketAddr`.
- Умеет работать с DNS (Точно так же как и с SocketAddr, но без порта).
- - Умеет сравнивать адреса (Для хранения заблокированных адресов в std::map и std::set).
