# 3. Конфигурационные файлы. /conf/iconf[.cpp / .hpp]
Модуль необходимый для парсинга конфигурационных файлов и передачи данных в ядро DPI.
Реализуется через чистый виртуальный класс IConf, он задаёт единый стиль для всех остальных реализаций. На основе этого базового класса можно реализовать абсолютной любой формат.

Планируется реализовать:
- YAML (Классика жанра)
- JSON (Мне нечего добавить по этому поводу)
- TOML (Если хоцца Rust'а)
- XML (Я люблю виндавс и циску)
