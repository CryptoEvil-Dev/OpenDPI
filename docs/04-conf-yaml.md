# 4. Парсер YAML-файлов. /conf/yaml[.cpp / .hpp]
**RyamlConfigReader** — реализация **IConfigReader** для парсинга **YAML** файлов.
Использует **ryml** и скрывает заголовочные файлы (иначе бы пришлось тащить всю библиотеку c4 и ryml к пользователю) через **PIMPL**.
Переопределяет только два метода:
- `get_value()`: для получения значения (например из map)
- `get_sequence()`: для массивов (aka, перечислений).

## Особенности парсера
Не ругается на дубли, использует первую попавшуюся ноду!
Пример:
```yaml
node:
    - 1
    - 2
    - 3
node:
    - 5
    - 6
    - 7
```

При запросе перечисления node вернёт [1, 2, 3].
