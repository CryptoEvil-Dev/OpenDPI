# 2. Абстракции над сетью. /net/tcp[.cpp / .hpp]

## net::TcpStream
Поток общения между двумя устройствами:
- Позволяет установить TCP подключение с устройством через `SocketAddr`.
- Возвращается когда клиент подключается к `TcpListener` через статический метод `bind`.
- Может работать как в блокирующем, так и в неблокирующим режиме. В неблокирующем режиме, если данных для чтения нет, вернётся -1, в блокирующем - произоёдт блокировка.

## net::TcpStream (read, write)
**Вход**:
- Принимают std::span<char>, перед чтением или отправкой пакета, необходимо задать размер буфера (Например: `buffer.resize(1500)`).

**Выход**:
- Возвращают `IoResult`, 16 байтовая структура (Благодаря размеру, возвращается через регистры, что очень быстро).

`IoResult` содержит в себе:
- `bytes`: Количество прочитанных байт.
- `serr`: Код ошибки, берётся и `errno` сразу же как ошибка была поймана.
- `result`: Результат работы IO-операции.
Содержит в себе функции для проверки статуса:
- `ok()` : Операция завершена успешно
- `would_block()` : Можно интрпретировать так же как и `EAGAIN`, попробуй ещё раз.
- `closed()` : Соеднение было закррыто.
- `error()` : Произошла ошибка, посмотри в serr.

## net::TcpListener
Слушатель входящих соединений:
- Устанавливает соединение с клиентом через `accept`, возвращает TcpStream.
- Может работать в неблокирующем режиме, но пока что это не рекомендуется (Над неблокирующим слушателем ещё ведётся работа).
